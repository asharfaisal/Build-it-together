AI Life Tracker — Complete Figma UI/UX Design Prompt

Design a premium, modern, responsive web application called “LifeTrack AI” — an AI-powered personal productivity and progress tracking platform that combines study tracking, workout tracking, task management, analytics, planning, and an AI personal coach into one unified application.

The application should feel like a polished SaaS product that could realistically be launched commercially. Avoid making it look like a generic to-do list, basic fitness app, or standard dashboard template.

The visual identity should communicate:

- Intelligence
- Productivity
- Discipline
- Personal growth
- Progress
- Calmness
- Premium technology

Use excellent typography, strong spacing, sophisticated cards, subtle visual hierarchy, tasteful gradients, and polished micro-interactions.

---

1. Overall Design Direction

Create a minimal, premium, modern dashboard experience.

The design should combine elements of:

- Premium SaaS dashboards
- Modern productivity applications
- Fitness analytics applications
- AI assistants
- Personal finance dashboards

Do NOT overcrowd the interface.

Use generous whitespace, strong hierarchy, rounded cards, subtle borders, and carefully controlled accent colors.

The UI should feel sophisticated rather than overly colorful.

Avoid excessive gradients, excessive glassmorphism, excessive shadows, or overly futuristic neon styling.

3. Color System

Create a complete color system using Figma variables.

Light Mode

Background:

- Primary background: very light neutral
- Secondary background: slightly darker neutral
- Card background: white

Text:

- Primary: deep charcoal
- Secondary: muted gray
- Tertiary: lighter gray

Use a sophisticated primary accent such as:

Emerald / Mint / Teal

Suggested direction:

- Primary: #19B88F
- Secondary accent: #5B8DEF
- Highlight: warm amber for achievements

Use accent colors sparingly.

Dark Mode

Background:

- Primary: deep navy/charcoal
- Secondary: slightly lighter navy
- Cards: dark elevated surfaces

Suggested direction:

- Primary background: #0B0F14
- Secondary background: #111821
- Card: #151D27

Text:

- Primary: near-white
- Secondary: muted cool gray
- Tertiary: darker gray

Accent:

- Mint/emerald
- Subtle blue secondary accent
- Amber for achievements

Make sure every color has a corresponding Light and Dark mode variable.
